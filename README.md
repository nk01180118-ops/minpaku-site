# Guesthouse Alegre 公式サイト（下書き）

一棟貸しの民泊の公式サイトです。構成は [そばハウス安曇野](https://sobahouse.jp/) を参考にしています。
静的サイト（HTML / CSS / JavaScript）なので、ビルドは不要です。`index.html` をブラウザで開けば表示できます。

## 構成

```
index.html      ページ本体（日本語）
en/index.html   英語版
pt/index.html   ポルトガル語版（ブラジル）
styles.css      スタイル
script.js       メニュー開閉 / ヒーローのスライドショー / スクロール演出 / 写真の拡大表示
assets/images/  宿の写真（Google ドライブ「トニーさん写真」から選んで長辺1600pxに縮小。hero-sp-*.jpg はスマホ用に縦長に切り抜いたもの）
```

ページ内のセクション：ヒーロー / コンセプト / ねる（寝室2部屋）/ くつろぐ（リビング）/ つくる（キッチン）/ 設備・アメニティ / ギャラリー / ご利用案内 / アクセス / ご予約

## 掲載内容について

- 宿の住所（町名・番地）は、あえて載せていません。予約が確定したあとにお客さんへ伝えます。
- 所在地・時刻・定員・届出番号・注意事項・予約リンクは、Airbnb の掲載ページの内容です。
- 仮の内容は残っていません。

## 更新するとき

ファイルを変えたら、公開する前に `./bump-version.sh` を実行してください。
版番号が新しくなり、スマホに古いページが残っていても、開いたときに自動で最新版に読み込み直されます。
